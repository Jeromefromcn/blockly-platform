# Dev Log — 2026-03-24

## Feature: Full Authentication & Role-Based Access Control

### Overview

Implemented a complete authentication and RBAC system covering:
- JWT authentication via httpOnly cookie
- Three roles: SUPER_ADMIN (from config), TUTOR, and STUDENT (from DB)
- Configurable permissions per role (TUTOR/STUDENT) stored in DB
- Super admin user management: create, list, reset password, force logout, delete, CSV batch import
- User self-service profile and password change
- Full frontend integration: login page, protected routes, nav bar, super admin panel, profile page

---

### Backend Changes

#### `backend/pom.xml`
- Added: `spring-boot-starter-security`
- Added: `jjwt-api`, `jjwt-impl`, `jjwt-jackson` (version 0.12.6)

#### `backend/src/main/resources/application.yml`
- Added `super-admin.username` and `super-admin.password` (env var overrides)
- Added `jwt.secret` and `jwt.expiry-hours`

#### `backend/src/main/resources/schema.sql`
- Added `users` table (id, username, password_hash, role, display_name, email, enabled, token_version, created_at)
- Added `role_permissions` table (role + permission composite PK)

#### New: `entity/User.java`
- JPA entity for the `users` table with all required fields

#### New: `entity/RolePermission.java`
- JPA entity with composite key (role + permission)

#### New: `repository/UserRepository.java`
- `findByUsername`, `existsByUsername`

#### New: `repository/RolePermissionRepository.java`
- `findByRole`, `deleteByRole`

#### New: `service/JwtService.java`
- `generateToken(username, role, tokenVersion)` — creates signed JWT
- `validateToken(token)` — parses and verifies JWT, returns Claims
- `extractUsername`, `extractTokenVersion`

#### New: `service/AuthService.java`
- `login(username, password)` — checks super admin first (from config), then DB users
- `isSuperAdmin(username)` — case-insensitive comparison to configured username

#### New: `service/UserService.java`
- `createUser`, `listUsers`, `resetPassword`, `forceLogout`, `deleteUser`
- `importCsv(MultipartFile)` — parses CSV with columns: username, password, role
- `updateProfile`, `changePassword`
- `getPermissions(role)`, `setPermissions(role, permissions)`
- Default password for new/reset users: `12345678`

#### New: `config/JwtAuthFilter.java`
- `OncePerRequestFilter` — extracts JWT from httpOnly cookie `auth_token`
- Validates token and checks `tokenVersion` against DB (or 0 for super admin)
- Sets `SecurityContextHolder` with username and `ROLE_<ROLE>` authority

#### New: `config/SecurityConfig.java`
- Disables CSRF (SPA pattern)
- Stateless session
- Public routes: `POST /api/auth/login`, `POST /api/auth/logout`, `/actuator/**`
- All `/api/**` routes require authentication
- Installs `JwtAuthFilter` before `UsernamePasswordAuthenticationFilter`
- Defines `PasswordEncoder` (BCrypt) bean
- Enables `@EnableMethodSecurity` for `@PreAuthorize`

#### Modified: `config/WebConfig.java`
- Changed `allowedOrigins("*")` to `allowedOriginPatterns("*")` with `allowCredentials(true)` to support cookies

#### New: `controller/AuthController.java`
- `POST /api/auth/login` — validates credentials, sets httpOnly cookie, returns `{username, role, permissions[]}`
- `POST /api/auth/logout` — clears cookie
- `GET /api/auth/me` — returns current user info + permissions

#### New: `controller/UserController.java`
- All routes under `/api/admin/**`, all guarded with `@PreAuthorize("hasRole('SUPER_ADMIN')")`
- `GET /api/admin/users`
- `POST /api/admin/users`
- `DELETE /api/admin/users/{id}`
- `POST /api/admin/users/{id}/reset-password`
- `POST /api/admin/users/{id}/force-logout`
- `POST /api/admin/users/import-csv`
- `GET /api/admin/permissions/{role}`
- `PUT /api/admin/permissions/{role}`

#### New: `controller/ProfileController.java`
- `GET /api/profile`
- `PUT /api/profile`
- `PUT /api/profile/password` — blocked for SUPER_ADMIN

#### Test config: `src/test/resources/application.properties`
- Added `super-admin.*` and `jwt.*` properties for potential context-loading tests

### Frontend Changes

#### New: `src/api.js`
- Fetch wrapper with `credentials: 'include'` on all requests
- Auto-redirects to `/login` on 401
- Exports: `apiGet`, `apiPost`, `apiPut`, `apiPatch`, `apiDelete`

#### New: `src/context/AuthContext.jsx`
- `AuthProvider` — fetches `/api/auth/me` on mount
- Stores: `user {username, role, permissions[]}`
- Methods: `login(username, password)`, `logout()`, `fetchMe()`, `hasPermission(perm)`
- Exports: `AuthProvider`, `useAuth` hook

#### New: `src/components/ProtectedRoute.jsx`
- Redirects to `/login` if not authenticated
- Shows 403 for `superAdminOnly` or `permission` mismatch

#### New: `src/pages/Login.jsx`
- Username + password form
- Calls `useAuth().login()`, navigates to `/` on success

#### New: `src/pages/Profile.jsx`
- Shows username (read-only), display name, email (editable)
- Save Profile → `PUT /api/profile`
- Change Password section (hidden for SUPER_ADMIN) → `PUT /api/profile/password`

#### New: `src/pages/SuperAdminPanel.jsx`
- Tab 1 (Users): table of all users with reset password, force logout, delete actions
  - Create User modal form
  - CSV import (file upload)
- Tab 2 (Permissions): per-role permission checkboxes for TUTOR and STUDENT

#### Modified: `src/App.jsx`
- Wrapped with `<AuthProvider>`
- Added routes: `/login` (public), `/super-admin` (super admin only), `/profile` (protected)
- Wrapped `/admin` routes with `ProtectedRoute permission="MANAGE_EXERCISES"`
- Wrapped `/` and `/exercise/:id` with `ProtectedRoute`
- NavBar: shows Admin Panel link if `MANAGE_EXERCISES` permission, User Management link for SUPER_ADMIN
- NavBar: shows logged-in username (→ profile) and Logout button

#### Modified: `src/pages/Home.jsx`, `Admin.jsx`, `AdminEditor.jsx`, `Workspace.jsx`
- Replaced raw `fetch()` calls with `apiGet`, `apiPost`, `apiPut`, `apiPatch`, `apiDelete` from `api.js`
- File uploads retain direct `fetch` but add `credentials: 'include'`
