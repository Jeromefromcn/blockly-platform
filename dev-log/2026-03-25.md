## Bug Fixes

### Like Feature (double fix)
1. **403 Forbidden** — `POST /api/exercises/*/like` was missing from Spring Security `permitAll` list
2. **Toggle logic** — backend returned `liked: true` even on repeat clicks; fixed to actual delete + decrement
3. **crypto.randomUUID() on HTTP** — `crypto.randomUUID()` requires HTTPS; calling it on plain HTTP threw silently inside `catch {}`, preventing the request from ever being sent. Fixed with `Math.random()` UUID fallback in `Home.jsx`

### Run button opened browser print dialog
- Blockly `text_print` block generates `print(...)` calls; sandbox only injected `console`, not `print`, so `window.print()` was called
- Fixed in both `AdminEditor.jsx` and `Workspace.jsx` by adding `print` as a second injected parameter

### Output panel blocked Blockly trashcan
- Overlay approach (`position: absolute`) covered both the toolbox and trashcan
- Fixed by moving output panel into the sidebar (below Clear button)

### grading_mode column too small (VARCHAR 20 → TEXT)
- After grading aspect JSON was stored, MySQL truncated the value
- Fixed via V3 Flyway migration: `ALTER TABLE exercise_versions MODIFY COLUMN grading_mode TEXT NOT NULL`
