## Fix: Blockly Module Import Error in Grading Panel

### Problem
`executeCode()` used `window.Blockly` which does not exist — Blockly is bundled as an ES module, not a global.

### Fix
- Added `import * as Blockly from 'blockly'` and `import { javascriptGenerator } from 'blockly/javascript'` to Admin.jsx
- `executeCode()` now uses the imported `Blockly` and `javascriptGenerator` directly

### Files Changed
- `frontend/src/pages/Admin.jsx` — Added Blockly ES module imports; updated `executeCode()`
